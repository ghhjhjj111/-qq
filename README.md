## 二、核心功能模块

### 1. 搭子动态 / 需求发布

用户自主发布找搭子帖子，可选择游玩类型、时间、地点、人数、性别要求、费用 AA / 主办方承担；支持图文上传、标签选择（羽毛球、探店、爬山、桌游、剧本杀、露营、看电影、健身等）；帖子后台审核，违规内容拦截，展示在同城广场，支持附近优先排序。

### 2. 线下活动组局模块

主办方可以创建公开活动，填写活动主题、时间地点、集合位置、名额、报名费、活动介绍；其他用户在线报名、支付活动费用；支持查看报名名单、活动签到、活动相册；活动可设置是否需要审核报名人，控制入局人员，适合桌游局、户外团建、兴趣聚会。

### 3. 陪约 / 助教服务（特色板块）

助教、陪玩、技能达人入驻上架服务项目，例如游戏陪玩、运动助教、学习辅导、探店陪同、摄影跟拍等；设置服务价格、服务范围、是否支持上门、服务时长；用户直接预约下单，选择服务时间，在线支付定金或者全款，订单流转到服务商，完成服务后确认收货。

> 
> 提示：运营时严格遵守法规，平台禁止色情、违规陪侍相关服务，仅做兴趣、技能、正常游玩结伴。

### 4. 附近搭子、用户主页

LBS 定位，按距离展示同城用户、正在招募的搭子局；个人主页展示发布记录、参与过的活动、服务评价、头像简介；支持关注、私信私聊沟通，发送文字图片。

### 5. 商家 / 达人入驻管理

陪玩助教、本地兴趣商家申请入驻，后台审核资质；入驻后上架服务、发布活动；平台可设置抽佣比例，每一笔订单平台自动抽成，作为平台收益。

### 6. 订单与财务体系

活动报名订单、陪约服务订单统一管理；支持微信 H5 支付；订单状态：待付款、待确认、进行中、已完成、退款；评价体系，用户完成订单后给对方打分写评价；资金流水、提现申请，入驻达人 / 商家可申请余额提现，后台审核打款。

### 7. 分销分享裂变

每个活动、个人主页生成分享海报，分享好友注册下单，推广人获得佣金；分销记录、佣金明细、提现记录后台可查，帮助平台快速引流拉新。

### 8. 消息通知

订单变动通知、活动报名提醒、私信消息、审核结果通知，微信模板消息提醒用户。

### 9. 后台管理功能

- 用户管理：会员列表、封禁用户、实名认证（可选开启）
- 内容审核：搭子帖子、活动内容、服务项目审核
- 分类管理：自定义游玩分类、服务标签
- 订单财务：订单列表、抽佣设置、提现审核、资金流水
- 评价管理：管理用户评价，删除违规评价
